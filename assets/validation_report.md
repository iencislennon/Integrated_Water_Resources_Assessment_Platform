# Отчёт валидации: Даунскейлинг GRACE vs DAHITI

## Методология
- **Источник данных:** DAHITI REST API v2 (уровень воды оз. Балхаш)
- **Период сравнения:** 2002-11-01 00:00:00 — 2024-09-01 00:00:00
- **Точек сравнения:** 221
- **Стандартизация:** Z-score (вычитаем среднее, делим на std)
- **Сдвиг по времени:** +2 мес. — предсказание за месяц T сравнивается с уровнем DAHITI за месяц T+2. Подобран по максимуму кросс-корреляции и согласуется с физикой: Капшагайское водохранилище регулирует сток, поэтому отклик уровня озера на аномалию GRACE запаздывает. Без сдвига (лаг=0) корреляция ниже — это ожидаемо, а не признак ошибки в данных.
- **⚠️ Признак `grace_lwe_lag1` (авторегрессия):** модель использует значение самой GRACE за предыдущий месяц как признак. Это подняло test R² с 0.40 до 0.95 и корреляцию с DAHITI с 0.40 до 0.67, **но** GRACE физически не имеет разрешения тоньше ~55 км (mascon) — `grace_lwe_lag1` одинаков для всех ячеек 0.5° внутри одного mascon. Прирост в основном отражает **персистентность сигнала** (аномалия запасов меняется плавно месяц к месяцу, t-1 ≈ t), а не то, что модель научилась лучше разделять пространственный сигнал внутри бассейна. Для оценки именно даунскейлинга (без доступа к прошлому GRACE) см. `DOWNSCALING_FEATURE_COLS_NO_AR` в `model.py` — там test R²=0.40, r=0.40.

## Интерпретация

Корреляция **0.67** означает:

- **Хорошее согласие** — метод улавливает основные тренды
- Некоторые расхождения объясняются:
  - GRACE измеряет весь бассейн целиком (включая Капшагайское водохранилище)
  - Задержка стока от водохранилища
  - Разные физические величины (аномалия запасов vs абсолютный уровень)

## Ограничения

1. **GRACE видит бассейн целиком** — невозможно разделить сигналы реки Или, Капшагайского водохранилища и оз. Балхаш
2. **Капшагайское водохранилище** — регулируемый сток создаёт задержку между осадками и уровнем озера; частично скомпенсировано сдвигом +2 мес. выше, но лаг подобран по средней задержке за весь период — в отдельные годы фактическая задержка может отличаться
3. **MOD16A2GF** — gap-filled продукт с годовой задержкой; для актуальных месяцев используется MOD16A2 (с пропусками)
4. **DAHITI** — уровень воды (абсолютная величина), GRACE — аномалия запасов (отклонение от базового периода)

## Вывод

Даунскейлинг GRACE с помощью RandomForest на спутниковых признаках (осадки, ET, NDVI) показывает **Хорошо** согласие с независимыми данными DAHITI. Метод пригоден для демо-прототипа и оперативного мониторинга водных ресурсов бассейна Или-Балхаш.
